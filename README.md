# Tendie Studio

Редактор анимированных обоев PosterBoard (.tendies) прямо на iPhone.
Три состояния — **Сон / Блокировка / Домой**. Каждый слой (фото, градиент, текст, форма)
имеет своё положение, размер, поворот и прозрачность в каждом состоянии, а переход между
состояниями анимируется (длительность, задержка, пружина). Плюс бесконечные петли (парение, вращение, пульс, покачивание).

## Сборка IPA (без Mac)
1. Создай репозиторий на GitHub, залей содержимое папки.
2. Actions → **Build IPA** → Run workflow.
3. Скачай артефакт `TendieStudio.ipa` и поставь через AltStore / SideStore / TrollStore.

Локально на Mac: `brew install xcodegen && xcodegen generate && open TendieStudio.xcodeproj`.

## Как пользоваться
1. Собери сцену: «Блокировка» — как обои выглядят на экране блокировки, «Домой» — как будут выглядеть на главном экране.
2. Переключайся между состояниями — слои сами проигрывают переход. Кнопка ▶ запускает Сон → Блокировка → Домой.
3. Экспорт → один раз выбери любой рабочий `.tendies` как **основу** → «Собрать» → поделись файлом в Pocket Poster.

## Что не проверено (важно)
Код написан без Xcode и не компилировался. Формат CAML для PosterBoard не документирован Apple —
собрано по открытым описаниям (OpenPoster, CAPlayground, Nugget). Самые рискованные места:
- `beginTime` в переходах (задержка) и бесконечные петли (`additive`, `repeatCount="Inf"`);
- ось Y/знак поворота (корень объявлен с `geometryFlipped="1"`);
- служебный `assetManifest.caml` из основы не пересоздаётся.
Если обои не применяются или анимация ведёт себя странно — пришли мне `main.caml` из рабочего файла, поправлю генератор.
