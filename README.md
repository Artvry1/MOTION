# MOTION — iOS wallpaper studio

Первый рабочий каркас проекта для iOS. Разработка ведётся на Windows, сборка — в GitHub Actions на macOS.

## Что уже есть
- SwiftUI-интерфейс в тёмном глянцевом стиле с сине-фиолетовыми акцентами.
- Создание проекта.
- Импорт нескольких изображений из медиатеки через системный Photos Picker.
- Холст с перетаскиванием, масштабированием и поворотом выбранного изображения.
- Сохранение списка проектов локально (метаданные и изображения — в Documents).

## Что пока не реализовано
- Ручная обрезка по контуру.
- Удаление белого/любого фона.
- Таймлайн и ключевые кадры.
- Импорт/экспорт `.tendies`.

Это стартовая версия, не готовый редактор `.tendies`.

## Облачная сборка
1. Создайте репозиторий GitHub и загрузите содержимое этой папки.
2. В GitHub откройте **Actions** и разрешите запуск workflows.
3. Запустите workflow **Build MOTION (unsigned)** через вкладку Actions или отправьте commit в `main`.
4. Скачайте артефакт `MOTION-unsigned-ipa`.

Важно: unsigned IPA — это результат компиляции, но он **не подписан и не устанавливается напрямую** на iPhone. Для установки потребуется подписать приложение подходящим сертификатом и provisioning profile либо импортировать сборку в поддерживаемый процесс подписи. Не публикуйте сертификаты, приватные ключи или пароли в репозитории.

## Идентификатор приложения
Сейчас используется временный Bundle ID `com.example.motionstudio`. Перед подписанием замените его на свой уникальный идентификатор в `project.yml`.
